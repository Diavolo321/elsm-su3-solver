# Независимые проверки (verification)

Скрипты, которыми обоснованы исправления 2026-10-18. Для работы пакета не нужны.

| Скрипт | Что проверяет | Запуск (из этой папки) |
|---|---|---|
| `derive.py` | Массы из лагранжиана (Eqs. 2, 5) против формул таблицы A1; находит опечатки η_NS и K0* (сравнение с напечатанными формулами) | `python derive.py` |
| `reconstruct.py` | Восстанавливает вакуум авторов (σx = 2m_q/g = 0.109) и показывает, почему PCAC-вакуум (σx = 0.126) даёт m_π ≈ 436 МэВ; гипотезы по каону | `python reconstruct.py` |
| `tscan.py` | T_χ для четырёх вариантов таблицы III (около 2 мин, пишет CSV в текущую папку) | `python tscan.py` |

Нужны numpy и scipy; `tscan.py` использует пакет из `../src`.
